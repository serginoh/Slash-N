Chapitre 01 - Installer-Mac_+_Windows_+_Linux

Fiche pratique : concepts web clés, environnements locaux (WampServer, MAMP, XAMPP) et module Readline.

1. Introduction au PHP

Qu'est-ce que PHP ?

PHP (Hypertext Preprocessor) est un langage de script exécuté côté serveur. Il permet de transformer des pages statiques en sites web dynamiques en traitant les requêtes en amont et en générant le code HTML à la volée.

À quoi sert PHP ?

PHP gère l'ensemble de la logique applicative : réception et traitement des formulaires, gestion des sessions et cookies, sécurisation des accès, interactions avec les bases de données (MySQL, MariaDB, PostgreSQL), et communication avec des API tierces.

2. Rôles et comparaison : HTML, CSS, JavaScript et PHP

Chaque technologie remplit un rôle précis et complémentaire dans une application web standard :

Technologie Exécution Rôle principal
HTML Client (Navigateur) Structure et balisage sémantique de la page (titres, paragraphes, médias, formulaires).
CSS Client (Navigateur) Présentation visuelle, design, typographie, mise en page et adaptation responsive.
JavaScript Client (Navigateur) Dynamisme et interactivité côté utilisateur sans rechargement (manipulation DOM, AJAX/Fetch).
PHP Serveur Web Logique métier, sécurité, calculs, requêtes en base de données et génération du HTML.

Fonctionnement d'une requête

L'utilisateur saisit une adresse ou clique sur un lien. Le serveur web intercepte la requête, transmet le script au moteur PHP, exécute la logique de traitement, puis renvoie le code HTML final au navigateur. Le client n'a jamais accès au code source PHP brut.

3. Introduction à Docker

Docker est une plateforme de conteneurisation qui permet d'isoler une application et l'ensemble de ses dépendances (serveur web, version précise de PHP, base de données) dans un environnement standardisé et reproductible. Cela garantit que le projet s'exécute de façon strictement identique sur toutes les machines, sans conflit de versions.

Note d'installation Docker : Si vous préférez installer et utiliser Docker plutôt qu'un serveur tout-en-un local classique, les installeurs officiels (Docker Desktop pour Windows et macOS, paquets officiels pour Linux) ainsi que la documentation complète sont disponibles directement sur le site officiel : https://www.docker.com.

4. Installation des environnements locaux (avec module Readline)

Pourquoi le module Readline ?

Le module Readline permet d'interagir confortablement en ligne de commande (CLI), d'activer la complétion automatique, d'éditer les saisies et de conserver l'historique des commandes dans les scripts PHP interactifs ou le shell interactif (php -a).

Windows : WampServer

  1. Téléchargez WampServer (64 bits recommandé) sur le site officiel (wampserver.aviatechno.net ou wampserver.com).
  2. Assurez-vous d'avoir installé tous les packages redistribuables Microsoft Visual C++ requis avant de lancer l'installation.
  3. Suivez l'assistant d'installation en conservant le chemin par défaut (C:\wamp64).
  4. Lancez WampServer et vérifiez que l'icône dans la zone de notification devient verte (services Apache et MySQL actifs).

Activation de l'extension Readline sur WampServer :

  • Clic gauche sur l'icône verte WampServer > PHP > Extensions PHP > cochez php_readline.
  • Alternative via le fichier de configuration : ouvrez php.ini (disponible via le menu Wamp), recherchez la ligne ;extension=readline et retirez le point-virgule initial pour obtenir : 
    extension=readline
  • Redémarrez les services WampServer (Clic gauche > Restart All Services).

macOS : MAMP

  1. Rendez-vous sur mamp.info et téléchargez la version adaptée à votre Mac (puce Apple Silicon M1/M2/M3/M4 ou processeur Intel).
  2. Ouvrez le fichier .pkg téléchargé et suivez les étapes d'installation (déposez MAMP dans /Applications).
  3. Ouvrez MAMP et cliquez sur « Start Servers » pour activer Apache et MySQL (racine web par défaut : /Applications/MAMP/htdocs).

Configuration et prise en charge de Readline sur macOS / MAMP :

  • MAMP intègre les modules PHP standards. Pour activer ou vérifier Readline, éditez le template de configuration php.ini de la version PHP active (accessible via MAMP > Preferences > PHP, ou dans /Applications/MAMP/bin/php/php[version]/conf/php.ini).
  • Vérifiez que la directive suivante est présente et décommentée : 
    extension=readline
  • Pour l'utilisation en terminal, assurez-vous d'ajouter le PHP de MAMP à votre PATH (.zshrc) ou utilisez le PHP compilé avec readline via Homebrew (brew install php readline).

Linux : XAMPP (LAMPP)

  1. Téléchargez l'installeur Linux 64 bits (.run) depuis apachefriends.org.
  2. Ouvrez un terminal, accordez les droits d'exécution et lancez l'installateur avec les privilèges root : 
    chmod +x xampp-linux-x64-*-installer.run
sudo ./xampp-linux-x64-*-installer.run
  3. Suivez l'assistant. XAMPP s'installe dans /opt/lampp. Démarrez l'ensemble des services via : 
    sudo /opt/lampp/lampp start

Configuration de Readline sous Linux / XAMPP :

  • Ouvrez le fichier de configuration principal de PHP situé dans /opt/lampp/etc/php.ini avec les droits d'administration : 
    sudo nano /opt/lampp/etc/php.ini
  • Vérifiez la présence de l'extension ou décommentez la ligne : 
    extension=readline
  • Si vous utilisez également PHP directement via les paquets de la distribution Linux (APT sur Debian/Ubuntu), veillez à installer la bibliothèque système correspondante : 
    sudo apt update && sudo apt install -y php-readline libreadline-dev

5. Vérification du bon fonctionnement

Pour valider que PHP et le module Readline sont bien fonctionnels sur votre machine :

  1. Dans un terminal, exécutez la commande suivante pour lister les modules chargés : 
    php -m | grep readline
  2. Lancez le shell interactif PHP afin de tester la saisie en direct et l'historique : 
    php -a
# Saisissez par exemple : echo 'Readline fonctionne parfaitement !';
  3. Créez un fichier info.php dans votre dossier racine web (www ou htdocs) contenant : 
    <?php
phpinfo();
?>
    Ouvrez http://localhost/info.php dans votre navigateur et recherchez la section readline pour confirmer son statut actif.
