Chapitre 02 – Variables

Introduction

Maintenant que PHP est installé, on peut commencer à travailler avec le langage. La manière la plus simple est de créer un fichier avec l’extension .php. Cette extension permet au serveur de comprendre qu’il s’agit d’un fichier PHP.

La balise PHP

Tout code PHP doit être placé entre les balises suivantes :

<?php
// Du code PHP ici
?>

Tout ce qui se trouve à l’intérieur de ces balises doit être du PHP valide. Ce qui est en dehors est affiché tel quel.

Les variables

Les variables permettent de stocker des valeurs en mémoire pour les réutiliser plus tard. Une variable commence toujours par un $ suivi de son nom : 

<?php
$nom = 'Dupont';
?>

Il n’est pas nécessaire de déclarer le type de la variable à l’avance. On peut utiliser des lettres, des chiffres et des underscores. Chaque instruction se termine par un point-virgule ;.

Les types de base

Les entiers (integers)

<?php
$note = 20;
?>

Les nombres décimaux (floats)

<?php
$prix = 12.5;
?>

Les chaînes de caractères (strings)

<?php
$prenom = "Sophie";
?>

Les booléens

<?php
$majeur = true;
$vaccine = false;
?>

Le type null

null représente une variable sans valeur. Si on affiche une variable null avec echo, rien n’apparaît. 

<?php
$vide = null;
echo $vide; // n'affiche rien
?>

Afficher une variable avec echo

Pour afficher une variable, on utilise l’instruction echo : 

<?php
$nom = 'Dupont';
echo $nom;
?>

Pour forcer un saut de ligne dans la sortie, on peut utiliser \n (surtout utile dans le terminal).

Opérations arithmétiques

On peut faire des calculs avec les variables numériques. Pensez à utiliser des parenthèses pour gérer la priorité des opérations : 

<?php
$note1 = 10;
$note2 = 15;
echo ($note1 + $note2) / 2; // Affiche 12.5
?>

La concaténation

Pour assembler des chaînes de caractères, on utilise le point . (et non le +) : 

<?php
$prenom = 'Marc';
$nom = 'Do';
echo $prenom . ' ' . $nom; // Affiche "Marc Do"
?>

Guillemets simples vs guillemets doubles

Les guillemets doubles permettent d’interpréter les variables et les caractères spéciaux (comme \n). Les guillemets simples affichent le texte tel quel. 

<?php
$prenom = "Marc";
echo "Bonjour $prenom"; // Affiche : Bonjour Marc
echo 'Bonjour $prenom'; // Affiche : Bonjour $prenom
?>

Si on a besoin d’utiliser le même type de guillemet à l’intérieur de la chaîne, on l’échappe avec un anti-slash : 

<?php
echo 'L\'apostrophe';
echo "Il a dit \"bonjour\"";
?>
