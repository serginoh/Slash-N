Chapitre 12 – Lecture des fichiers

Introduction

PHP permet de lire le contenu de fichiers texte présents sur le serveur. C’est utile pour charger des données, des configurations ou des logs.

Lire tout un fichier

La fonction file_get_contents() lit un fichier en une seule fois : 

<?php
$contenu = file_get_contents('donnees.txt');
echo $contenu;
?>

Lire un fichier ligne par ligne

On peut aussi transformer un fichier en tableau avec file() : 

<?php
$lignes = file('donnees.txt');

foreach ($lignes as $ligne) {
    echo $ligne . "<br>";
}
?>

Vérifier si un fichier existe

<?php
if (file_exists('donnees.txt')) {
    echo "Le fichier existe";
} else {
    echo "Fichier introuvable";
}
?>

Bonnes pratiques

  • Toujours vérifier que le fichier existe avant de le lire
  • Faire attention au chemin du fichier (relatif ou absolu)
  • Éviter de lire de très gros fichiers d’un seul coup
