Introduction

PHP propose de nombreuses fonctions internes (strlen(), str_replace()…). On peut aussi créer ses propres fonctions pour réutiliser du code facilement.

Définir une fonction

<?php
function bonjour($nom) {
    echo "Bonjour " . $nom;
}

bonjour("Jean");  // Affiche : Bonjour Jean
bonjour("Mario"); // Affiche : Bonjour Mario
?>

Les paramètres

Les paramètres permettent de passer des informations à la fonction. On peut aussi définir une valeur par défaut : 

<?php
function bonjour($nom = "visiteur") {
    return "Bonjour " . $nom;
}

echo bonjour();        // Bonjour visiteur
echo bonjour("Jean");  // Bonjour Jean
?>

La valeur de retour

Une fonction peut retourner une valeur avec le mot-clé return. Dès qu’un return est rencontré, la fonction s’arrête. 

<?php
function addition($a, $b) {
    return $a + $b;
}

$resultat = addition(5, 3);
echo $resultat; // Affiche 8
?>

La portée des variables

Une variable définie à l’extérieur d’une fonction n’est pas accessible à l’intérieur. Il faut passer les données en paramètres. 

<?php
$nom = "Jean";

function bonjour($nom) {
    return "Bonjour " . $nom;
}

echo bonjour($nom);
?>

Le typage

Depuis PHP 7, on peut préciser le type des paramètres et de la valeur de retour : 

<?php
function bonjour(string $nom): string {
    return "Bonjour " . $nom;
}
?>
