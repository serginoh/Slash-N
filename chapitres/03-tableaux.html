Chapitre 03 – Les tableaux

Introduction

Imaginons qu’on doive sauvegarder plusieurs notes d’un élève. Créer une variable pour chaque note devient vite ingérable. Les tableaux permettent de stocker une liste de valeurs dans une seule variable.

Les tableaux indexés

Pour créer un tableau, on utilise les crochets et on sépare les valeurs par des virgules : 

<?php
$notes = [10, 20, 9, 8];
?>

Chaque valeur est accessible via son index. Attention : les index commencent à 0. 

<?php
echo $notes[1]; // Affiche 20
echo $notes[3]; // Affiche 8
?>

Les tableaux associatifs

On peut aussi donner des noms (clés) aux valeurs avec la syntaxe => : 

<?php
$eleve = [
    'nom' => 'Doe',
    'prenom' => 'Jean',
    'notes' => [10, 20, 15]
];
?>

Pour accéder à une valeur, on utilise la clé :

<?php
echo $eleve['prenom']; // Affiche Jean
echo $eleve['prenom'] . ' ' . $eleve['nom']; // Affiche Jean Doe
?>

Modifier et ajouter des valeurs

<?php
$eleve['prenom'] = 'Marc';     // Modifie une valeur
$eleve['notes'][] = 16;       // Ajoute une note à la fin
?>

Tableaux imbriqués

Un tableau peut contenir d’autres tableaux :

<?php
$classe = [
    [
        'nom' => 'Doe',
        'prenom' => 'Jean',
        'notes' => [16, 14, 18]
    ],
    [
        'nom' => 'Doe',
        'prenom' => 'Jane',
        'notes' => [12, 15, 17]
    ]
];

echo $classe[1]['notes'][1]; // Affiche 15
?>

Déboguer un tableau

Pour afficher le contenu d’un tableau, on utilise print_r() : 

<?php
print_r($eleve['notes']);
?>
