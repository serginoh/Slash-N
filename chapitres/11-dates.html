Chapitre 11 – Les dates

Introduction

PHP permet de manipuler facilement les dates et les heures. La fonction la plus utilisée est date().

Afficher la date actuelle

<?php
echo date('d/m/Y');        // 10/11/2026
echo date('H:i:s');        // 20:15:30
echo date('d/m/Y H:i');    // 10/11/2026 20:15
?>

Les formats utiles

  • d → jour (01 à 31)
  • m → mois (01 à 12)
  • Y → année (2026)
  • H → heure (00 à 23)
  • i → minutes
  • s → secondes

Timestamp

Un timestamp est le nombre de secondes écoulées depuis le 1er janvier 1970. On l’obtient avec time() : 

<?php
echo time(); // Exemple : 1794336000
?>

Créer une date précise

<?php
$date = mktime(0, 0, 0, 12, 25, 2026); // 25 décembre 2026
echo date('d/m/Y', $date);
?>

Comparer des dates

<?php
$aujourdhui = time();
$noel = mktime(0, 0, 0, 12, 25, 2026);

if ($aujourdhui < $noel) {
    echo "Noël n'est pas encore passé";
}
?>
