Chapitre 14 – Les cookies

Introduction

Les cookies sont de petits fichiers de données enregistrés par un site internet dans le navigateur d'un utilisateur. Ils permettent de conserver certaines informations entre plusieurs visites ou pages d'un même site.

Par exemple, les cookies peuvent être utilisés pour mémoriser les préférences d'un utilisateur, conserver son choix de langue ou garder certaines informations de navigation.

Contrairement aux variables classiques de PHP, qui disparaissent à la fin de l'exécution du script, les cookies peuvent conserver des informations pendant une durée déterminée.

Créer un cookie avec setcookie()

Pour créer un cookie en PHP, on utilise la fonction setcookie().

Cette fonction permet de définir le nom du cookie, sa valeur et sa durée de conservation. 

<?php
setcookie("prenom", "Sophie", time() + 3600);
?>

Dans cet exemple :

  • prenom correspond au nom du cookie.
  • Sophie correspond à sa valeur.
  • time() + 3600 définit sa date d'expiration.

La fonction time() retourne le timestamp actuel, c'est-à-dire le nombre de secondes écoulées depuis le 1er janvier 1970.

En ajoutant 3600 secondes, le cookie expirera après une heure.

Attention : la fonction setcookie() doit être appelée avant l'envoi de contenu au navigateur, notamment avant le moindre HTML ou espace affiché.

Définir la durée de vie d'un cookie

La durée de vie d'un cookie est définie grâce à son timestamp d'expiration.

Voici quelques exemples de durées : 

<?php
// 10 minutes
setcookie("test", "valeur", time() + 600);

// 1 heure
setcookie("test", "valeur", time() + 3600);

// 1 jour
setcookie("test", "valeur", time() + 86400);

// 7 jours
setcookie("test", "valeur", time() + (7 * 86400));

// 30 jours
setcookie("test", "valeur", time() + (30 * 86400));
?>

Si aucune date d'expiration n'est définie, le cookie est généralement conservé uniquement pendant la session du navigateur.

Lire un cookie avec $_COOKIE

Pour récupérer la valeur d'un cookie, PHP met à disposition la superglobale $_COOKIE.

Il s'agit d'un tableau associatif contenant les cookies transmis par le navigateur au serveur. 

<?php
setcookie("prenom", "Sophie", time() + 3600);
?>

<?php
if (isset($_COOKIE["prenom"])) {
    echo "Bonjour " . $_COOKIE["prenom"];
} else {
    echo "Aucun prénom enregistré.";
}
?>

La fonction isset() permet de vérifier si le cookie existe.

Attention : un cookie créé avec setcookie() n'est généralement disponible dans $_COOKIE qu'à partir de la requête HTTP suivante.

Il faut donc actualiser la page pour pouvoir lire le cookie qui vient d'être créé.

Modifier un cookie

Pour modifier un cookie, il suffit d'utiliser à nouveau setcookie() avec le même nom, mais une nouvelle valeur. 

<?php
setcookie("prenom", "Marc", time() + 3600);
?>

Ici, le cookie nommé prenom contiendra désormais la valeur Marc.

Il est important de conserver les mêmes paramètres de chemin et de domaine si ceux-ci ont été définis lors de la création du cookie.

Supprimer un cookie

Pour supprimer un cookie, on peut lui attribuer une date d'expiration située dans le passé. 

<?php
setcookie("prenom", "", time() - 3600);
?>

En définissant une date d'expiration passée, le navigateur est invité à supprimer le cookie.

Pour que cela fonctionne correctement, il faut utiliser les mêmes paramètres de chemin et de domaine que ceux utilisés lors de sa création.

Les options de sécurité des cookies

Les cookies peuvent contenir des informations importantes. Il est donc nécessaire de prendre certaines précautions pour éviter qu'ils soient utilisés de manière malveillante.

PHP permet de définir plusieurs options lors de la création d'un cookie. 

<?php
setcookie("prenom", "Sophie", [
    "expires" => time() + 3600,
    "path" => "/",
    "secure" => true,
    "httponly" => true,
    "samesite" => "Lax"
]);
?>

Voici le rôle de chaque option :

  • expires : définit la date d'expiration du cookie.
  • path : définit les pages du site pour lesquelles le cookie est envoyé.
  • secure : indique que le cookie doit être transmis uniquement par une connexion HTTPS.
  • httponly : empêche l'accès au cookie depuis JavaScript côté navigateur.
  • samesite : limite l'envoi du cookie dans certaines requêtes provenant d'autres sites.

La valeur Lax est souvent un bon choix par défaut pour l'option samesite.

Attention : l'option secure nécessite une connexion HTTPS pour que le navigateur transmette le cookie.

Exemple pratique : mémoriser un prénom

Maintenant que nous connaissons les principales fonctions, réalisons un petit exemple permettant de mémoriser le prénom d'un visiteur.

Si le visiteur a déjà enregistré son prénom, le site lui affiche un message de bienvenue personnalisé. Sinon, un message lui indique qu'il n'est pas encore connu. 

<?php
if (isset($_POST["prenom"])) {

    $prenom = htmlspecialchars(
        $_POST["prenom"],
        ENT_QUOTES,
        "UTF-8"
    );

    setcookie("prenom", $prenom, [
        "expires" => time() + (7 * 86400),
        "path" => "/",
        "secure" => true,
        "httponly" => true,
        "samesite" => "Lax"
    ]);

    header("Location: cookies.php");
    exit;
}
?>

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Bienvenue</title>
</head>

<body>

    <?php if (isset($_COOKIE["prenom"])) { ?>

        <h1>
            Bonjour
            <?= htmlspecialchars(
                $_COOKIE["prenom"],
                ENT_QUOTES,
                "UTF-8"
            ) ?> !
        </h1>

    <?php } else { ?>

        <h1>Bienvenue sur notre site !</h1>

        <form method="POST">
            <label for="prenom">Votre prénom :</label>

            <input type="text" id="prenom" name="prenom" required>

            <button type="submit">Enregistrer</button>
        </form>

    <?php } ?>

</body>
</html>

Dans cet exemple :

  • Le formulaire permet au visiteur d'envoyer son prénom.
  • PHP récupère l'information grâce à $_POST.
  • htmlspecialchars() protège les données affichées.
  • setcookie() enregistre le prénom pendant sept jours.
  • header() redirige vers la page pour lire le cookie lors de la requête suivante.

Cet exemple est volontairement simple. Dans un véritable site, il faudrait également valider les données reçues et gérer correctement le consentement aux cookies lorsque celui-ci est nécessaire.

Cookies et sessions : quelle différence ?

Les cookies et les sessions permettent tous les deux de conserver des informations entre plusieurs requêtes. Cependant, leur fonctionnement est différent.

  • Cookies : les informations sont stockées dans le navigateur de l'utilisateur.
  • Sessions : les informations sont stockées côté serveur. Le navigateur conserve généralement un cookie contenant l'identifiant de session.

Les cookies sont pratiques pour mémoriser des préférences, tandis que les sessions sont généralement utilisées pour gérer les connexions des utilisateurs.

Nous verrons plus en détail le fonctionnement des sessions dans le prochain chapitre.

Conclusion

Les cookies sont très utiles pour améliorer l'expérience des visiteurs et conserver certaines informations entre plusieurs visites.

Voici les principales notions à retenir :

  • setcookie() : permet de créer ou modifier un cookie.
  • $_COOKIE : permet de lire les cookies reçus.
  • time() : permet de définir une date d'expiration.
  • isset() : permet de vérifier l'existence d'un cookie.
  • Une date d'expiration passée permet de supprimer un cookie.
  • httponly, secure et samesite améliorent la sécurité.

Dans le prochain chapitre, nous découvrirons les sessions en PHP, qui permettent notamment de conserver les informations d'un utilisateur pendant sa navigation sur un site.
