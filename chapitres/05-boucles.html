Chapitre 05 – Les boucles

Introduction

Les boucles permettent de répéter plusieurs fois une instruction ou un ensemble d'instructions sans devoir réécrire le même code.

Par exemple, si l'on souhaite afficher les nombres de 1 à 100, il serait peu pratique d'écrire 100 fois une instruction echo. Grâce aux boucles, PHP peut effectuer cette opération automatiquement.

PHP possède principalement quatre types de boucles : while, do...while, for et foreach.

La boucle while

La boucle while permet de répéter un morceau de code tant qu'une condition est vraie. 

<?php
$nombre = 1;

while ($nombre <= 5) {
    echo $nombre . "<br>";
    $nombre++;
}
?>

Dans cet exemple, PHP affiche les nombres de 1 à 5. La variable $nombre commence à 1 et augmente de 1 à chaque répétition grâce à l'opérateur ++.

Dès que $nombre dépasse 5, la condition devient fausse et la boucle s'arrête.

Attention aux boucles infinies

Il faut toujours faire attention à ce que la condition puisse devenir fausse. Sinon, la boucle risque de ne jamais s'arrêter. 

<?php
$nombre = 1;

while ($nombre <= 5) {
    echo $nombre;
    // Oubli de $nombre++
}
?>

Dans cet exemple, la variable ne change jamais de valeur. La condition reste donc toujours vraie : c'est une boucle infinie.

La boucle do...while

La boucle do...while ressemble à la boucle while, mais possède une différence importante : le code est exécuté au moins une fois avant de vérifier la condition. 

<?php
$nombre = 1;

do {
    echo $nombre . "<br>";
    $nombre++;
} while ($nombre <= 5);
?>

Ici, PHP exécute d'abord le contenu du do, puis vérifie la condition du while.

Différence entre while et do...while

Pour bien comprendre la différence, observons cet exemple : 

<?php
$nombre = 10;

// Avec while
while ($nombre <= 5) {
    echo "While exécuté";
}

// Avec do...while
do {
    echo "Do...while exécuté";
} while ($nombre <= 5);
?>

La boucle while ne s'exécute pas puisque la condition est fausse dès le départ.

En revanche, la boucle do...while s'exécute une fois avant de vérifier la condition.

La boucle for

La boucle for est particulièrement utile lorsque l'on connaît à l'avance le nombre de répétitions souhaitées. 

<?php
for ($i = 1; $i <= 5; $i++) {
    echo $i . "<br>";
}
?>

Cette boucle affiche les nombres de 1 à 5. Elle contient trois éléments importants :

  • $i = 1 : initialise la variable au début de la boucle.
  • $i <= 5 : définit la condition à respecter.
  • $i++ : augmente la variable de 1 après chaque répétition.

Ces trois éléments sont regroupés dans les parenthèses et séparés par des points-virgules.

Décrémentation

Il est également possible de faire fonctionner une boucle dans le sens inverse grâce à l'opérateur --. 

<?php
for ($i = 5; $i >= 1; $i--) {
    echo $i . "<br>";
}
?>

Ici, PHP affiche les nombres de 5 à 1. La variable diminue de 1 à chaque répétition.

La boucle foreach

La boucle foreach est principalement utilisée pour parcourir les tableaux. Elle permet de récupérer chaque élément sans devoir gérer manuellement un compteur.

Parcourir un tableau simple

<?php
$fruits = ["Pomme", "Banane", "Orange", "Fraise"];

foreach ($fruits as $fruit) {
    echo $fruit . "<br>";
}
?>

À chaque répétition, PHP récupère automatiquement l'élément suivant du tableau et le stocke dans la variable $fruit.

Récupérer les clés et les valeurs

Il est également possible de récupérer à la fois la clé et la valeur de chaque élément avec l'opérateur =>. 

<?php
$personne = [
    "prenom" => "Sophie",
    "nom" => "Dupont",
    "age" => 25
];

foreach ($personne as $cle => $valeur) {
    echo $cle . " : " . $valeur . "<br>";
}
?>

Dans cet exemple :

  • $cle contient le nom de la clé.
  • $valeur contient la valeur correspondante.

Cette méthode est particulièrement pratique pour parcourir des tableaux associatifs.

L'instruction break

L'instruction break permet d'arrêter immédiatement une boucle, même si sa condition est encore vraie. 

<?php
for ($i = 1; $i <= 10; $i++) {

    if ($i == 5) {
        break;
    }

    echo $i . "<br>";
}
?>

Dans cet exemple, la boucle s'arrête dès que la variable $i atteint 5.

Les nombres affichés seront donc 1, 2, 3 et 4.

L'instruction continue

L'instruction continue permet de passer directement à la répétition suivante sans exécuter le reste du code de la répétition actuelle. 

<?php
for ($i = 1; $i <= 5; $i++) {

    if ($i == 3) {
        continue;
    }

    echo $i . "<br>";
}
?>

Ici, lorsque $i vaut 3, PHP passe directement à la répétition suivante.

Les nombres affichés seront donc 1, 2, 4 et 5.

Différence entre break et continue

  • break : arrête complètement la boucle.
  • continue : passe à la répétition suivante.

Les boucles imbriquées

Il est possible de placer une boucle à l'intérieur d'une autre. On parle alors de boucles imbriquées.

Elles sont notamment utiles pour parcourir des tableaux à plusieurs dimensions ou effectuer des répétitions complexes. 

<?php
for ($i = 1; $i <= 3; $i++) {

    echo "Table de multiplication de $i :<br>";

    for ($j = 1; $j <= 5; $j++) {
        echo $i . " x " . $j . " = " . ($i * $j) . "<br>";
    }

    echo "<br>";
}
?>

La première boucle contrôle le nombre principal et la deuxième effectue les multiplications.

À chaque répétition de la boucle extérieure, la boucle intérieure est exécutée entièrement.

Quelle boucle choisir ?

Chaque boucle possède ses avantages. Le choix dépend principalement de la situation rencontrée.

  • while : lorsque le nombre de répétitions dépend d'une condition.
  • do...while : lorsque le code doit être exécuté au moins une fois.
  • for : lorsque le nombre de répétitions est connu à l'avance.
  • foreach : lorsque l'on souhaite parcourir un tableau.

Conclusion

Les boucles sont essentielles en PHP. Elles permettent d'automatiser les tâches répétitives et de rendre le code plus court et plus efficace.

Voici les principales notions à retenir :

  • while : répète du code tant qu'une condition est vraie.
  • do...while : exécute le code au moins une fois.
  • for : répète du code un nombre défini de fois.
  • foreach : parcourt les éléments d'un tableau.
  • break : arrête une boucle.
  • continue : passe à la répétition suivante.
